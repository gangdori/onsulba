# 온술바 🍸

간판 없는 빌딩 17층, 아는 사람만 올라가는 **온라인 루프탑 칵테일 바**.
로그인 없이 문을 두드리고 올라가 자리에 앉으면, 옆자리 손님과 텍스트로 대화하고 서로 원하면 실제 음성 통화까지 할 수 있습니다.

## 주요 기능

- **입장 연출** — 1층 골목의 간판 없는 문 → 전망 엘리베이터(도시 야경) → 루프탑 로비 → 호스트가 문을 열어 주면 걸어서 자리까지
- **실제로 줄 서는 대기열** — 성비가 맞지 않거나 자리가 없으면 로비의 로프 줄에 내 아바타가 서서 기다리고, 차례가 오면 문이 열림
- **루프탑 바 공간** — 유리벽 너머 도시 스카이라인, 퍼걸러와 줄조명, 튀어나온 바 3개가 ㄹ자(지그재그) 카운터로 이어지고 가운데 통로로 직원이 오가며 서빙
- **걸어서 이동** — 입장·자리 옮기기·퇴장 모두 카운터와 스툴을 피해 걷는 경로로 움직임 (순간이동 없음)
- **성비 맞춤** — 남/여 자리를 번갈아 배치해 옆자리는 항상 이성
- **칵테일 메뉴판과 직원 주문** — 자리에 앉으면 직원이 걸어와 종이 메뉴판을 건넴. `직원 부르기`로 언제든 다시 호출. 주문하면 직원이 백바에서 만들어 가져다줌
- **코인과 머무는 시간** — 하루에 한 번 코인 20개 지급. 한 잔 주문할 때마다 코인을 내고 그 잔의 시간(15~30분)만큼 머무름. 산 시간이 끝나면 자리에서 일어나야 함
- **3분 안에 첫 주문** — 앉은 뒤 3분 안에 주문하지 않으면 자리에서 내보내고, 5분 동안 다시 올라올 수 없음
- **옆자리 대화** — 왼쪽/오른쪽 손님과 1:1 채팅, 같은 바 전체 채팅, 말풍선
- **실제 음성 통화** — 옆자리 손님에게 통화 요청 → 상대가 수락하면 WebRTC(P2P)로 연결
- 건배 🍻, 차단, 새로고침·잠깐 끊김 시 자리 유지, 느린 기기에서 자동 화질 조정

### 코인 규칙

- 코인은 **기기 단위**(브라우저에 저장된 기기 ID)로 관리하고, 한국 날짜 기준 하루 한 번 `DAILY_COINS` 만큼 지급합니다 (최대 `COIN_CAP` 까지 누적).
- 입장은 무료지만 앉은 뒤 `ORDER_GRACE_MS`(3분) 안에 첫 잔을 주문해야 합니다. 나갔다 다시 와도 이 마감은 늘어나지 않습니다.
- 산 시간이 남아 있는 동안에는 나갔다 다시 들어와도 추가 주문 없이 머물 수 있습니다.
- 서버가 재시작돼도 이어지도록, 서버가 서명한 지갑 사본을 브라우저가 보관합니다. 서명 키는 `WALLET_SECRET`.
- 로그인이 없으므로 브라우저 데이터를 지우면 새 기기로 인식되어 다시 지급받을 수 있습니다. 실제 유료 재화로 쓰려면 계정과 DB가 필요합니다.
- 메뉴·가격·시간은 `shared/layout.js` 의 `DRINKS`, `WALLET` 에서 바꿉니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
npm test           # 좌석 배정·대기열·서버 프로토콜 테스트
```

혼자 테스트할 때는 브라우저 탭을 두 개 열어 남성/여성으로 각각 입장하면 옆자리에 배정됩니다.

## 배포

**Vercel** — 저장소를 연결하면 그대로 배포됩니다 (`vercel.json`, 진입점 `server.js`, 서울 리전).
빌드 단계(`npm run build`)가 브라우저용 라이브러리를 `public/` 으로 복사합니다.

- Vercel Functions 는 일정 시간마다 WebSocket 연결을 끊습니다. 화면은 자동으로 다시 연결하고 자리·통화는 유지됩니다.
- 손님 상태는 서버 인스턴스의 메모리에만 있습니다. 재배포하거나 한동안 아무도 없어 인스턴스가 내려가면 초기화되고,
  접속이 몰려 인스턴스가 여러 개로 늘어나면 손님이 서로 다른 바로 나뉠 수 있습니다.
  규모가 커지면 공유 저장소(Redis 등)나 상시 실행 서버(`Dockerfile` 포함)로 옮기세요.

**공통**

- 마이크(통화)는 브라우저 정책상 **HTTPS** 에서만 동작합니다 (localhost 제외).
- 통화는 기본적으로 공개 STUN 서버를 씁니다. 일부 통신사/회사 네트워크에서는 TURN 서버가 있어야 연결되므로 실서비스에서는 `ICE_SERVERS` 로 지정하세요.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `MAX_GENDER_GAP` | `2` | 허용하는 남녀 인원 차이. 이를 넘기면 많은 쪽 성별은 대기 |
| `GRACE_MS` | `20000` | 연결이 끊긴 뒤 자리를 지켜 주는 시간(ms) |
| `DAILY_COINS` | `20` | 하루에 한 번 지급하는 코인 |
| `COIN_CAP` | `40` | 쌓아 둘 수 있는 코인 상한 |
| `WALLET_SECRET` | 자동 | 지갑 사본 서명 키. 배포 환경에서는 임의의 긴 문자열로 직접 설정 권장 |
| `STAY_SCALE` | `1` | 체류 시간 배율 (시험할 때 `0.05` 처럼 줄임) |
| `ORDER_GRACE_MS` | `180000` | 앉은 뒤 첫 주문까지 주어지는 시간(ms) |
| `GRACE_COOLDOWN_MS` | `300000` | 주문 없이 나간 뒤 다시 올라올 수 있을 때까지(ms) |
| `ICE_SERVERS` | 공개 STUN | WebRTC ICE 서버 JSON. 예: `[{"urls":"turn:turn.example.com","username":"u","credential":"p"}]` |

## 구조

```
shared/layout.js             좌석·공간 배치, 걷는 경로, 칵테일 메뉴·코인 규칙 (서버와 화면이 함께 쓰는 단일 기준)
server/bar.js                좌석 배정 · 성비 균형 · 대기열 (순수 로직)
server/index.js              정적 파일 + WebSocket (입장/채팅/통화 신호 중계, 코인·체류 시간)
public/js/scene.js           3D 연출 총괄: 카메라, 걷는 손님, 직원, 이름표
public/js/world-city.js      밤하늘·스카이라인·빌딩 외벽·1층 골목
public/js/world-elevator.js  전망 엘리베이터
public/js/world-roof.js      루프탑 바와 대기 로비
public/js/kit.js             사람(앉기/서기/걷기)·칵테일 모델, 공용 재질
public/js/voice.js           음성 통화 (WebRTC)
public/js/main.js            화면 흐름과 UI
```

3D 공간은 외부 모델 파일 없이 전부 코드로 만든 도형입니다 (three.js 내장 기능만 사용).
